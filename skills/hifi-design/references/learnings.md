# Learnings

The dated proof behind rules in SKILL.md and its references. The rule lives at its step; this file keeps the case that taught it, so a later pause can tell a principle from a workaround and re-test the workaround on a newer model. Read it at the skill pause, before writing a new rule (the rule may already exist), and when a rule looks arbitrary. Newest entries at the bottom of each section. Prompts that produced a bad first pass live in `failed-prompts.md` instead.
