# The end-to-end review

Go live's end-to-end review step. Read it when the step opens. Fresh-context `worker` agents, read-only, check the built product against everything upstream (Model: worker role), one lane each:

- **Interface polish:** better-ui per surface with build's `references/judge-siblings.md`, findings only.
- **Goals to working screens:** every goal and Overall Shape item has a place in the running app that serves it.
- **States:** every state in Solution Details is reachable in the build.
- **Numbers:** the same number agrees across surfaces and with the data.
- **Copy:** it matches the spec and DESIGN.md.
- **Motion as specced:** every row of the motion tables at its token, duration, easing, and reduced-motion outcome; nothing moving that no table lists; the code judged against review-animations' standards; each finding confirmed at its `file:line` before it's reported.
- **Stats:** the stats on screen pass the check the research set.
- **Carried items:** the open questions and the tech toggle each closed or carried.

Output: one merged list sorted into fixes and calls, the calls asked with a lean, each resolved one pushed as it's answered.
