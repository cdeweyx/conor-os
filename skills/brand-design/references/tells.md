# Tells and the reflex test

What models and templates default to, and how to stay off it. Dated October 2026; marked measured or practice.

Each tell is tagged by how it's caught: **[grep]** a search of the token file or source finds it, **[shot]** only a screenshot shows it, **[run]** it needs the running app (a hover, a load, a theme flip). Run the grep ones before any critic sees the work (`check.mjs` covers the named hexes and fonts; search for the rest by hand); shot and run ones go to the gate screenshots and the critics. Tag every new entry (shape from expo's `native-slop.md`).

## The reflex test

Bans move the model to the next default, so this file isn't a ban list. For every font, color, and mark in a direction, ask: would I propose this same choice for another brand in this category? If yes, change it, or keep it and write a one-line reason from the brief into the direction's "defaults kept" field. At least one full board uses none of the defaults below. On six briefs this cut default hits from 4.38 per answer to 0.28 (fatihaydost, measured).

Score the cluster, not the single item. Inter is on 1.4% of the web; one default is a choice, three is a template.

## Model defaults (measured)

From 180 answers across 30 briefs and six models (fatihaydost, 2026):
- Palette: cream or warm off-white ground, terracotta accent, gold secondary.
- Display type: Fraunces (24% overall, 40% from Opus). Text type: Inter (40%).
- Mark: the product's object plus a hidden letter inside a circle, in 97 to 100% of answers.

From 120 AI-built sites, script-counted (buildtolaunch, 2026): Lucide as the only icon set 63% [grep], default shadcn colors with one button changed 61% [grep], Inter or no font chosen 60% [grep], one accent-colored headline word 52% [shot], sparkle, bolt, or brain icons 47% [grep].

## Clichés (practice)

- **Marks** [shot]: hexagon, orbit, spiral, swoosh, globe, overlapping loops, a letter in a rounded square, a gradient-filled mark, a 3D blob or glass render, a spark or star, a shield, a leaf, a bolt, a mark that only works at 512px.
- **Type** [grep]: Inter, Geist, Space Grotesk, Roboto, DM Sans, or no choice; Fraunces, Playfair, Instrument Serif as display; an all-caps geometric sans wordmark with wide tracking; a serif headline with one italic accent word.
- **Color** [grep the named hexes and `gradient`; shot for the rest]: indigo to purple or purple to pink gradients; blue-green gradients; cream with terracotta; near-black with one acid green or vermilion; soft pastels with a rounded sans; the framework's default accent.
- **Icons** [grep the import names]: sparkles, lightning, brain, wand; one thin line set as the only illustration [shot].
- **System:** a beautiful board over an unchanged product [shot]; the brand only in the logo corner [shot]; the chart palette untouched [grep]; tiny tracked uppercase labels everywhere [grep]; a pulsing status dot [run]; the hero's device stamped on every card to lift a critic score [shot] ("way, way worse").
- **Imagery** [shot]: stock 3D blobs, isometric scenes, AI people, "handmade" organic shapes with no hand.
- **The escape clichés** [shot]: where models land after leaving purple. Cream and serif, italic serif display, acid on black, broadsheet hairlines everywhere, numbered section labels. These are now as generic as purple.

## Name three before drawing

In the brand idea step (SKILL step 2), before any direction, name the three clichés of the product's own category (for fitness: neon green on black, a lightning bolt or flame, a dumbbell). They join the deny list for this run.
